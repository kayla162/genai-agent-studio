# 品牌定位
Kayla 精緻少女是以植萃與溫和配方為核心的保養品牌，主張「精緻不費力」的日常保養。

品牌個性：溫柔、知性、帶一點少女感，不浮誇、不說教。

# 目標客群
主要客群為 22–35 歲、重視成分與質感的上班族女性，習慣在 IG 與電商平台比較成分後購買。

她們在意溫和不刺激、使用感受與包裝質感，對誇張的效果宣稱反感。

# 文案語氣
標題以 4–8 字為一行，兩行對仗或遞進，例如「給肌膚一場／溫柔的晨曦對話」。

副標說明成分或使用感受，不超過 22 字；避免驚嘆號連用與網路流行語。

科研語氣時可以寫成分名稱與濃度，但不寫未經驗證的數據，例如吸收倍數、臨床百分比。

# 常用賣點說法
水楊酸類產品寫「調理粉刺肌」「代謝老廢角質」，不寫「消除痘痘」「根治粉刺」。

保濕類產品寫「長效保濕」「舒緩乾燥不適」，不寫「修復受損肌膚」。

# 色彩規範
品牌主色 #B8A5D6（薰衣草紫），輔助色 #F9F4E8（暖米白），點綴色 #C9A96E（柔金），文字色 #3A3335。

背景以淡紫、米白、霧面金為主，避免螢光色與高飽和的紅、綠、藍；主色色差 ΔE2000 不超過 5。

# Logo 使用規範
Logo 置於左上角，四周保留至少 0.5 倍 Logo 高度的淨空區，不得與標題、商品或徽章重疊。

淺色背景使用深色 Logo；不可變形、加陰影或更改顏色。

# 字型規範
標題使用 Noto Serif TC 粗體，內文與價格使用 Noto Sans TC；英文副標可全大寫並加寬字距。

# 版面與構圖
商品主體佔畫面 20–50%，整體留白至少 30%；商品置於右側或中央偏下，文字靠左對齊網格。

促銷徽章放在商品左側或左下，不可蓋住商品標籤；價格與徽章不要同時放在最上方。

# 各通路注意事項
IG 貼文以品牌感為主，促銷資訊精簡；限時動態上方 14% 與下方 20% 避免放重要文字（會被介面遮住）。

電商主圖背景簡潔、商品清楚，促銷文字不超過畫面 20%。

# 廣告法規
一般化粧品不得宣稱醫療效能，例如治療、消炎、根治；不得使用「美白」「淡斑」等需另行核准的特定用途宣稱，除非產品已取得許可。

不使用「最有效」「第一」「保證」等誇大或絕對用語；效果相關描述需加註「效果因個人體質與膚況而異」。
