## 錄影前準備

- 清掉不相關的任務與通知；瀏覽器只留一個分頁，關掉書籤列。
- 先跑一次同樣的需求，讓 ComfyUI 與 RAG 模型都已載入（第一張圖要多花載入模型的時間）。
- 想展示 Query Rewriting 時，選第一輪容易失敗的組合（例如需求裡寫「保證有效」），或在 mock 模式的 Demo 控制台開啟「第一輪刻意失誤」另外錄一段。
- 不要拍到 `.env`、Gemini key 或 Cloudflare 的設定頁。
